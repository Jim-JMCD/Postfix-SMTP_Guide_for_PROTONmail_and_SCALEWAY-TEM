This guide describes how setup up Postfix to work with Proton Mail and Scaleway Transactional Email (TEM) secure SMTP services. Postfix when configured to work with a SMTP relay provides system and application administrators to use native and application mail tools to send reports, alerts and other information to external email addresses. The SMTP services of Proton and Scaleway are different in configuration requirements because they are designed for different workloads.
